# مراجع الكود العربي لـ GitHub

نسخة مجانية عملية تعمل داخل **GitHub Actions** وتضيف تقريرًا عربيًا تلقائيًا إلى Pull Request. لا تحتاج إلى خادم أو قاعدة بيانات أو مفتاح API.

## ما الذي تفحصه النسخة الأولى؟

- أسرار ومفاتيح API محتملة داخل الملفات.
- استخدام `eval` و`exec`.
- الأسطر الطويلة جدًا.
- تعليقات `TODO` و`FIXME`.
- ملخص عربي داخل Pull Request.
- فحص الملفات المتغيرة فقط لتقليل الوقت والتكلفة.
- إعدادات لكل مشروع عبر `.arabic-reviewer.toml`.
- واجهة عربية للصق الكود أو رفع ملف Python من الهاتف.
- أزرار للشرح والترجمة والإصلاح مع عرض الأصلي والمعدل وسبب كل تغيير.
- كشف أخطاء صياغة Python وفحص تغييرات Pull Request فقط، مع بوابة تمنع الدمج عند ملاحظات عالية الخطورة.

> هذه أداة مساعدة أولية وليست بديلًا عن المراجعة البشرية أو أدوات الأمن المتخصصة.

الشرح والترجمة في الواجهة الحالية قواعدية ومحلية وليسا فهمًا توليديًا بالذكاء الاصطناعي. أي طبقة AI مستقبلية يجب أن تعمل عبر خادم آمن لا يضع المفاتيح داخل صفحة الموقع.

## التشغيل محليًا

```bash
python3 reviewer/main.py .
python3 reviewer/main.py . --format json
python3 -m pytest
```

يعيد البرنامج رمز خروج غير صفري عند العثور على ملاحظة عالية الخطورة، ما يسمح بإيقاف الدمج عند الحاجة.

## تفعيلها في مستودعك

1. انسخ مجلدي `reviewer` و`.github` إلى مستودعك.
2. من إعدادات المستودع، فعّل Actions إن كانت متوقفة.
3. افتح Pull Request تجريبيًا.
4. سيشغل GitHub الفحص وينشر تعليقًا عربيًا قابلًا للتحديث.

يجب أن يسمح المستودع للـ workflow بكتابة تعليقات Pull Requests عبر `GITHUB_TOKEN`. في Pull Requests القادمة من Fork قد تمنع GitHub الكتابة لأسباب أمنية.

## بدء الربح بدون دفع

ابدأ بخدمة تركيب وتخصيص للشركات الصغيرة: ركّب الأداة على مستودع تجريبي، قدّم تقريرًا أوليًا، ثم بع إعداد القواعد، تنظيف الأسرار، والتقارير الشهرية. راجع [FREE_START.md](FREE_START.md) لرسالة التواصل والخطوات. صفحة عرض جاهزة موجودة في `site/index.html` ويمكن نشرها لاحقًا على GitHub Pages.

## بنية المشروع

```text
.
├── .github/workflows/arabic-review.yml  # التشغيل التلقائي
├── reviewer/main.py                     # محرك الفحص والتقرير
├── tests/test_reviewer.py               # اختبارات الوحدة
├── .arabic-reviewer.toml                # إعدادات الفحص لكل مستودع
├── FREE_START.md                         # بدء مجاني واختبار الربح
├── site/index.html                       # صفحة العرض والتسعير
├── pyproject.toml
└── README.md
```

## خارطة التطوير

- دعم ESLint وRuff وSemgrep وGitleaks.
- إعدادات قواعد عبر ملف YAML.
- تلخيص تغييرات Pull Request.
- دعم نموذج ذكاء اصطناعي اختياري مع حد استخدام.
- لوحة تقارير اختيارية.
- خطط مجانية ومدفوعة بعد اختبار الطلب الحقيقي.
