# مراجع الكود العربي لـ GitHub

نسخة أولية مجانية تعمل داخل **GitHub Actions** وتضيف تقريرًا عربيًا تلقائيًا إلى Pull Request. لا تحتاج إلى خادم أو قاعدة بيانات أو مفتاح API.

## ما الذي تفحصه النسخة الأولى؟

- أسرار ومفاتيح API محتملة داخل الملفات.
- استخدام `eval` و`exec`.
- الأسطر الطويلة جدًا.
- تعليقات `TODO` و`FIXME`.
- ملخص عربي داخل Pull Request.

> هذه أداة مساعدة أولية وليست بديلًا عن المراجعة البشرية أو أدوات الأمن المتخصصة.

## التشغيل محليًا

```bash
python3 reviewer/main.py .
python3 reviewer/main.py . --format json
python3 -m pytest
```

يعيد البرنامج رمز خروج غير صفري عند العثور على ملاحظة عالية الخطورة، ما يسمح بإيقاف الدمج عند الحاجة.

## تفعيلها في مستودعك

1. انسخ مجلدي `reviewer` و`.github` إلى مستودعك.
2. من إعدادات المستودع، فعّل Actions إن كانت متوقفة.
3. افتح Pull Request تجريبيًا.
4. سيشغل GitHub الفحص وينشر تعليقًا عربيًا قابلًا للتحديث.

يجب أن يسمح المستودع للـ workflow بكتابة تعليقات Pull Requests عبر `GITHUB_TOKEN`. في Pull Requests القادمة من Fork قد تمنع GitHub الكتابة لأسباب أمنية.

## بنية المشروع

```text
.
├── .github/workflows/arabic-review.yml  # التشغيل التلقائي
├── reviewer/main.py                     # محرك الفحص والتقرير
├── tests/test_reviewer.py               # اختبارات الوحدة
├── pyproject.toml
└── README.md
```

## خارطة التطوير

- دعم ESLint وRuff وSemgrep وGitleaks.
- إعدادات قواعد عبر ملف YAML.
- تلخيص تغييرات Pull Request.
- دعم نموذج ذكاء اصطناعي اختياري مع حد استخدام.
- لوحة تقارير اختيارية.
- خطط مجانية ومدفوعة بعد اختبار الطلب الحقيقي.
